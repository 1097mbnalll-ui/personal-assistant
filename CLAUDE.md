# الحرب العالمية — World War kingdom board game (browser)

Turn-based strategy game for a friend group (4 players), played in Chrome. Started as a Discord/paper
game (see `docs/original-idea.txt`), redesigned to last 30–60 minutes. The owner speaks Gulf Arabic:
**reply to the owner in Arabic**, keep the UI in Arabic (RTL).

## Owner's standing rules (important)
- **Show preview pictures before changing the live game** and wait for an explicit OK. No long code/prompt dumps.
- Goal for visuals: realistic and attractive. Interiors: "as realistic as possible". The WWII/Cold-War
  (classic) style is the approved base; modern and futuristic styles exist for the world map.
- Players will later play each from their **own phone** → views are tied to "the kingdom I control",
  not the active turn. Keep mobile performance in mind (touch joystick, quality tiers).
- Game length 30–60 min: 7 rounds, no player elimination.

## Build & test
- `python3 build.py` → concatenates `src/` into one self-contained `dist/index.html` (open in Chrome).
  Placeholders in `src/template.html`: `__3D__` (all JS) and `__DATA__` (`gamedata.json`).
  JS order: sim.js, inst.js, three_d.js, theme.js, room/room.js, room/building.js, realroom.js, interior.js.
- `tests/run.sh` → builds, then plays 4 full random games headless (hot-seat, 3 computer kingdoms, all-computer,
  and one walking inside buildings using every hotspot) and opens every institution screen each turn.
  Pass = `data-ok=[{"phase":"end","bad":[]...}...]`. If `google-chrome --dump-dom` prints nothing, use Playwright:
  `python3 build.py && python3 tests/mk_tests.py [fast] && node tests/run.js $PWD/tests/t4.html` (`fast` skips the slow interior game, ~3 s). Without a GPU, Chrome needs
  `--use-angle=swiftshader --enable-unsafe-swiftshader` and long `--virtual-time-budget`; it's slow.
- `src/room/preview3.html` (office) and `src/room/pb.html?m=hq|def|intel|foreign&c=0..7` render the
  realistic engine standalone — use these to make preview screenshots for the owner.
- No external libraries (no three.js); everything is vanilla JS + raw WebGL1. Keep it dependency-free
  unless the owner agrees (the old hosting couldn't load CDNs; GitHub Pages can).

## Architecture
- `src/template.html` — game engine, UI, HUD, rules. Phases: event → market/administration (3 ops)
  → cards (secret, curtain overlay) → reveal → move → attack → resolve → income → end.
  Key fns: newGame, startRound, applyEvent, buy, openMinistry, defUp, buyMis, startAim/aimClick/launch,
  intelUp, spyReport, sabotage, proposePact, sendAid, breakPact, resolve, income, score.
- `src/sim.js` — **national simulation layer** shared by every institution. Per-kingdom state in `player.s`
  (stab, ready, tax, debt, infl, ind, fuel, tech, rd, dos, threat, brief, ew, cables, sig, ci), world state in `G`
  (wx weather, rel opinion matrix, sanc, crises, reps battle reports, hist). Hooks called by the engine:
  simInit (newGame), simRoundStart (startRound: weather, R&D progress/test failures, fuel, false alarms, crises,
  intel cycle), simCommit/atkMods/defMods/simBattleFx (resolve), simIntercept/simStrikeFx (launch),
  calcIncome/simSettle (income), natScore (score). `TECH` = research tree. Decisions (1 op each): setReady, setTax,
  borrow, repay, buildInd, buyFuel, startRD, sanction, liftSanction (free), envoy. `advisors(pi)` = recommendations.
- `src/inst.js` — institution terminals: `INST` (tabs = departments/rooms) and `VIEW[m][tab](pi,p,act)` render into the
  shared `#dlg` modal via `showMinistry()`; `openMinistry(m,pi,sitting,tab)`. `opsMap(pi,mode)` = schematic SVG ops
  display (cmd supply rings / ew radar + tracks / threat arrows). Also the computer-run kingdoms: aiMarket, aiCard,
  aiMove, aiAttack, aiAct (sync, used by tests), aiSchedule (timer, called from render()). `player.ai` flag.
- `src/gamedata.json` — 26 regions (name, kingdom k, size L/M/S, cap, polygon path, label pos, coastal),
  adjacency, sea/background, glyphs. Generated by `tools/realmap.py` / `tools/gamedata.py` (numpy, scipy, contourpy).
- `src/three_d.js` — 3D world map renderer (region extrusion, picking, kingdom mode enterK/renderKingdom).
- `src/theme.js` — 3 world themes `ww2 | modern | future` (TH, themeProps, buildSky, setTheme; saved in localStorage `wg_theme`).
- `src/interior.js` — ministry buildings on the map, missile FX, main loop `loop3D`, old box-style interior
  `buildInterior` (still used for collision, hotspots, fallback; hotspots with a `tab` open that department screen), first-person movement (fpStep, goTo,
  nearestHS, actHS), tower/window view, input (joystick, pointer, keys).
- `src/room/room.js` — **realistic renderer `RR`**: procedural texture atlas (×2 res via `RR.setK`),
  triplanar + bump, sun & spot shadow maps (PCF), 4 nearest point lights, mirrored floor reflection,
  SSAO, bloom, god rays + dust particles, ACES tonemap, supersampling, `R.q.refl/ao` quality flags,
  `R.resize`, live textures `R.setWin` (window view) / `R.setScr` (screens atlas). Geometry builder `RR.GB`
  (box, cb chamfer box, sb rounded box, cyl, tube, sph, drape, drape2).
- `src/room/building.js` — `RR.building(m, opts)`: the two-floor WWII ministry building, room per
  ministry (hq = the palace: situation map table, cabinet table, treasury desk, secure comms console;
  def: missile display, war table, consoles; intel: desks with monitors, server racks;
  foreign: round negotiation table, flags, globe), upper floor = minister's office.
  Coordinates must match `buildInterior` in interior.js (W=9, D=6, floor height F=3.4).
- `src/realroom.js` — `RRI` glue: own canvas over `#v3`, enter/leave, screen/window texture sync,
  auto quality downgrade if frame time > 42 ms, falls back to old interior if WebGL setup fails.
- `src/room/office*.js` — earlier standalone office prototypes (reference only).

## Game rules (summary)
Sizes L/M/S: troop cap 6/4/3, more income for big, ±1 combat bonus. Kingdom abilities: Mountains
(palace holds 9), Ports (+1 gold every 2 rounds), Desert (3 troops for price of 2), Plains (cap +2).
Combat: attacker > defender → defender loses all, attacker loses max(1, D-1); tie → both halve;
defender ≥ → attacker loses all. Ministers bronze/silver/diamond +1/+2/+3. Peace card, random events.
Score: regions + 1 per 3 gold + 2 for palace. Ministries: Defense (air defense lvls, normal/heavy
missiles, 1 launch per round), Intelligence (spy report, sabotage), Foreign (pacts, aid, break pact).

State simulation (sim.js), all numbers small on purpose to keep the 30–60 min length:
- Economy: income lines + industry (lvl 0–2), foreign trade, tax policy (−1/0/+2 gold vs +5/0/−7 stability), army
  upkeep (>10 troops 1, >16 troops 2), readiness cost, debt interest (1 per 5), sanctions, inflation ≥15 → prices +1.
  Deficit → forced loan. Fuel 0–8: attack uses 1 (2 for ≥5 troops without logistics), missile 1; no fuel → attack −2.
- Stability 0–100: <40 → −1 combat, <25 → desertions and −1 income, ≥80 → +1 income. Score: +1 if ≥75, −1 per 5 debt.
- Readiness peace/alert/mobilization: alert +1 def & better interception; mobilization +1 atk +1 def, costly.
- R&D: cost, duration in rounds, prerequisites, industry/intel requirements, test stage that can fail (+1 round).
  Normal missile needs `rocket`, heavy needs `heavy`. 1 research slot, 2 with industry.
- Combat = troops + modifiers (command, terrain, doctrine, readiness, supply range to palace/camp, fuel, morale, weather).
- Early warning: detection early/late/missed by radar tech, AD level, readiness, weather, enemy guidance; interception
  is a roll; false alarms without the integrated network; civil defense reduces casualties.
- Intelligence: reports are estimates with confidence %, source, collection round, uncertainty note; may be delayed a
  round (intel 0), wrong, or verified by a second source. Border threat assessment every round. Never show another
  kingdom's hidden state (gold, tech, readiness, fuel) to a player except through these reports.
- Diplomacy: opinion matrix, reputation, sanctions, envoys, crises (opinion ≤ −50), one inherited rivalry + friendship.
- Computer kingdoms pursue a rival, react to threat level, research by personality, sign/refuse pacts by opinion.
