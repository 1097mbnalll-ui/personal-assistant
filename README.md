# الحرب العالمية

لعبة استراتيجية بالأدوار لـ 4 لاعبين في المتصفح.

- العب: افتح `dist/index.html` في كروم.
- البناء بعد أي تعديل: `python3 build.py`
- الاختبار: `tests/run.sh` (أو `python3 tests/mk_tests.py && node tests/run.js $PWD/tests/t4.html`)

اللعبة فيها محاكاة دولة كاملة: قيادة وطنية (غرفة عمليات، مجلس وزراء، خزانة)، وزارة دفاع (قيادة، إنذار مبكر، بحث وتطوير، تسليح)،
استخبارات (تقدير تهديدات، ملفات دول بنسبة ثقة ومصدر)، وخارجية (معاهدات، عقوبات، أزمات)، وممالك يديرها الحاسوب.

تفاصيل المشروع والقواعد في `CLAUDE.md`.
